# Seofyme SEO

Original WordPress SEO plugin by Seofyme — **not a fork or copy of any competitor**.

## Strategy

Seofyme owns its meta keys (`_seofyme_*`), namespaces (`SeofymeSEO\`), UI, scoring rules, and feature modules. Feature goals may overlap with what other SEO plugins offer (redirects, sitemaps, schema, etc.), but the implementation and product direction are Seofyme’s.

## Features

**Core**
- SEO title, meta description, canonical, robots
- Focus keyphrase + content/readability analysis
- XML sitemaps (`/sitemap.xml`)
- Schema.org JSON-LD
- SERP preview in the editor

**Advanced (bundled)**
- Redirect manager (CSV + slug-change prompts)
- Up to 5 related keyphrases + synonyms
- Internal linking suggestions
- Orphaned / cornerstone workouts
- Social previews (Open Graph / X)
- AI title & meta drafting + bulk approve
- Content planner / starter drafts
- AI bot blocker
- IndexNow
- Schema aggregation (`/seofyme-schema.json`)
- Local SEO (locations + store locator shortcode)
- Video SEO + News SEO sitemaps
- Front-end SEO inspector

## Requirements

- WordPress 6.0+
- PHP 7.4+

## Install

1. Upload the `seofyme-seo` folder to `wp-content/plugins/`
2. Activate **Seofyme SEO**
3. Open **Seofyme SEO → Settings**
4. Save **Settings → Permalinks** once to flush rewrite rules
