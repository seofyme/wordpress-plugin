All-in-one WordPress SEO with content analysis, schema, redirects, multi-keyphrase, internal linking, AI drafting, Local/Video/News SEO.

== Description ==

Seofyme SEO combines a GPL fork of Yoast SEO free with original premium-parity modules:

* Redirect manager (CSV bulk + automatic prompts)
* Multiple keyphrases (up to 5) with synonyms
* Internal linking suggestions & orphaned content workouts
* Social previews for Facebook and X
* AI title / meta drafting and bulk metadata editor
* Content planner with starter drafts
* AI bot blocker & IndexNow
* Schema aggregation graph
* Local SEO, Video SEO, News SEO
* Front-end SEO inspector

== Installation ==

1. Upload the `seofyme-seo` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu
3. Open SEO → Seofyme Tools to configure optional AI / bot / IndexNow settings
4. Save Permalinks once to flush rewrite rules
